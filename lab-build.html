Penetration Testing Lab Build

Designing and building a six-VM isolated lab for hands-on security testing, fully segmented so nothing touches the home network.

Goal

I wanted a safe, self-contained environment where I could practice scanning, enumeration, and vulnerability assessment without any risk to a real network. The whole lab runs in VMware Workstation on a single isolated network segment, so the machines can only see each other.

Environment

Six virtual machines: one Parrot Security box as the attacker/scanner, and five targets built around a small Windows Active Directory domain plus one deliberately vulnerable Linux box used as a practice target.

How I built it

1. Network isolation

Every adapter is set to the same private VMware LAN segment, with no connection to the host network or the internet during testing. VMware doesn't hand out addresses on that segment, so the primary domain controller runs DHCP for the lab.

2. The attacker box

I installed and updated Parrot Security, set its hostname and user, and added the scanning and assessment tools I'd need. I took a clean snapshot before installing Nessus so I could roll back instead of rebuilding if anything broke.

3. The Active Directory domain

I built the targets in dependency order, starting with DC01: static IP, Active Directory Domain Services, DNS, and a DHCP scope for the lab. DC02 joined as a second domain controller, 00Seven as a member server, and the Windows 10 client joined the domain as a normal user workstation.

4. The vulnerable target

Metasploitable2 is an intentionally insecure Linux image meant for training. It stays on the isolated segment only and never goes online. It gives me a realistic set of weaknesses to find and report against.

5. Vulnerability scanner

I installed Nessus Essentials on the Parrot box, confirmed the service was running, and let it compile its plugins — ready to scan the five targets.

What I practiced: virtualization and networking, Windows Server and Active Directory setup, Linux administration, and standing up a vulnerability scanner — the foundation every assessment is built on.

Reusable result

The lab is snapshotted at each stage and documented end to end, so I can reset it to a clean state and reuse it across courses instead of rebuilding from scratch. It's the base environment for the scanning, footprinting, and assessment projects in this portfolio.
