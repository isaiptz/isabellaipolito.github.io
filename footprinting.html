Information Gathering & Footprinting

Mapping an unknown network from the attacker's seat — operating systems, open ports, hostnames, and how the machines relate.

Goal

Footprinting is the first phase of any assessment: before you can evaluate a network you have to understand what's on it. From my Parrot box I used three tools to discover the five lab machines and build a clear picture of each one.

Method

Host discovery

A ping sweep across the lab subnet found every live host and its IP address, one target at a time.

Service and OS fingerprinting

For each machine I ran a service-version and OS-detection scan to identify the operating system, hostname, and which ports and services were open. I confirmed the results in Zenmap's graphical view, whose scripts also pulled details like exact OS build and domain membership.

Traffic visualization

EtherApe showed the scan traffic live as a graph — each host a node, each conversation a line — which made it easy to see the scanner reaching each target and to spot normal background domain traffic between the Windows machines.

Reading the map

  • Metasploitable2 exposed the most — 23 open ports — making it the widest attack surface on the network.
  • Ten, the Windows 10 client, exposed the least, with only four ports open.
  • The open ports on DC01 (DNS, Kerberos, LDAP, SMB) are exactly what you'd expect on a domain controller and confirmed its role.
  • All the Windows machines belong to the same PROTECTOR domain, and none of them require SMB signing — a configuration weakness worth flagging.

Takeaway: careful footprinting turns an unknown network into a labeled map. Knowing each host's OS, role, and exposure is what makes the next phase — assessing and prioritizing risk — possible.
